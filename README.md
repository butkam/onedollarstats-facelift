# One Dollar Stats — редизайн дашборда

Прототип редизайну дашборда One Dollar Stats на прикладі проєкту news.poliakov.co.

## Файли

- `redesign.html` — прототип редизайну.
- `dashboard.html` — оригінальний знімок дашборда (Last 14 days), для порівняння.
- `dashboard-30d.html` — знімок за 30 днів, де видно баг зі зникненням осі X.
- `audit.md` — аудит дизайну та розбір бага осі X.

## Як переглянути

```bash
python3 -m http.server 4173
```

Потім відкрити http://localhost:4173/redesign.html.
